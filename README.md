# Jagadeesh Gopu — Software Developer & B.Tech Scholar Portfolio

A refined, high-performance personal portfolio built with **React 18**, **TypeScript**, **Tailwind CSS**, and **Vite**.

## 🌟 Key Features
- **3D Animated Interactive Portrait:**
  - Real-time mouse tracking with dynamic 3D perspective tilt (-10° to +10°).
  - Ambient glowing multi-colored halo (cyan, coral, emerald, indigo).
  - Dynamic light sheen reflection glare.
  - Active status pill (`🟢 Seeking Internships`) and modern high-tech framing.
  - Automatic fallback to high-tech geometric avatar if no image file is provided.
- **Professional Engineering Statements:**
  - Refactored all self-deprecating/casual statements into strong, confident, professional statements suitable for internships, engineering positions, and collaborative research.
  - Comprehensive highlights of Computer Science focus (Joy University &times; NIAT).
- **Interactive Projects Showcase:**
  - **Recall Call:** Intelligent phone call contextual reminder platform with interactive live phone call simulation widget.
  - **AI Credit & Rate-Limit Navigator:** Android utility app with interactive comparative matrix benchmarking free tiers and pricing across Google Gemini, OpenAI, Anthropic, and DeepSeek.
- **Academic Foundations:**
  - Detailed chronological education cards highlighting Grade 'A' Distinction (962/1000 - 96.2%) and Class X merit (571/600 - 95.2%).
- **Interactive Contact:**
  - One-click copy email feature with instant visual feedback.
  - Interactive email composer that prepares a structured inquiry directly in your client.
  - Verified links to LinkedIn and GitHub.

## 🚀 Running Locally

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

3. **Build for production:**
   ```bash
   npm run build
   ```

## 📷 Adding Your Custom Photo
To use your actual headshot:
1. Place your photo inside the `public/` folder.
2. Name it `jagadeesh-portrait.jpg` (or change the path in `src/components/ProfessionalPortrait.tsx`).
3. The card will automatically display your photo with full 3D tilt, holographic glow, and laser scanner animations.
